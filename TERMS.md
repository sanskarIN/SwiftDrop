SwiftDrop source code is licensed under the Apache License 2.0. See `LICENSE` for the controlling software license terms.

## Local transfer responsibility

SwiftDrop provides tools for user-initiated local-network transfer. You are responsible for having permission to send, receive, store, or redistribute the content you transfer and for complying with applicable law, organizational policy, device policy, and network policy.

Do not use SwiftDrop to distribute malware, unauthorized copyrighted material, stolen credentials, illegal content, or content you are not permitted to transfer.

## Received files

A file received from another device can be unsafe even when transport integrity succeeds. Integrity verification means the received bytes match the bytes declared by the sender; it does not mean the file is trustworthy or malware-free. SwiftDrop does not automatically open received files.

## Availability

Peer-to-peer transfer depends on device storage, permissions, firewall rules, local-network topology, operating-system background limits, and hardware. The project does not guarantee uninterrupted transfer, permanent availability, or data recovery. Keep backups of important data.

## Privacy

The current release is designed as a local-first, account-free transfer application. Its current data practices are described in `PRIVACY.md`. Future features that materially change those practices must update the privacy documentation before release.

## Security reports

Follow `SECURITY.md`. Security-sensitive details should be reported privately rather than posted publicly.
