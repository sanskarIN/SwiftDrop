## Security issues

Do not publish vulnerability details, private transfer data, pairing invitations, certificate private keys, or other secrets in a public GitHub issue. Follow `SECURITY.md` and report security-sensitive findings privately to **sanskarin@outlook.in**.

## Public issues

Use GitHub issues for non-sensitive reproducible bugs and feature requests. Include the platform, SwiftDrop version/commit, expected behavior, actual behavior, and minimal reproduction steps. Remove personal data and transferred content from logs before attaching them.

## Scope

Community support cannot guarantee a response time, device compatibility, data recovery, or restoration of a transfer interrupted by external operating-system, storage, network, or firewall policy. Keep independent backups of important files.
